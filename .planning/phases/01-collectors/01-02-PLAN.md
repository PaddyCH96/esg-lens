<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| GDELT HTTP response → GdeltCollector | JSON articles array from api.gdeltproject.org crosses trust boundary; fields title/url/seendate/domain are attacker-influenceable |
| ticker + aliases → GDELT query string | ticker and alias values become query param values; must never become URL host or inject URL control chars |
| NewsAPI config flag → NewsApiCollector | feature flag determines whether any network call is made; must default off to avoid unexpected paid usage |
| collector → raw_documents insert | RawDocument fields are persisted via DocumentRepo with content_hash UNIQUE |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | src/esg_lens/collectors/gdelt.py query | mitigate | Alic or bundle terms are quoted and joined with OR inside parentheses; ticker only appears as quoted query value never as host; URL is hardcoded to https://api.gdeltproject.org/api/v2/doc/doc — verify by grep query param construction contains hardcoded host |
| T-02-02 | Tampering | src/esg_lens/collectors/gdelt.py domain normalization | mitigate | Domain derived via urllib.parse.urlparse hostname lowercased and stripped of www., not via string split; test asserts www.reuters.com → reuters.com and BBC.COM → bbc.com; prevents w_src tier misclassification |
| T-02-03 | Information Disclosure | src/esg_lens/collectors/gdelt.py seendate | mitigate | Parse seendate to ISO-8601 UTC TEXT; store raw only on parse failure; never log full article body beyond title; limit stored fields to title/body/url/domain |
| T-02-04 | Denial of Service | src/esg_lens/collectors/gdelt.py chunking | mitigate | Raw query length check at 400 chars before encoding, chunk into 2 sequential queries with Warning log gdelt_query_chunked; merge dedup on content_hash avoids duplicate rows; test verifies 2 calls made when bundle exceeds limit |
| T-02-05 | Denial of Service | src/esg_lens/collectors/gdelt.py content_hash | mitigate | content_hash computed as sha256 lower title piped with external_id or url prevents re-insert storms; INSERT OR IGNORE on (ticker, content_hash) dedups; regex for hash not ReDoS — simple sha256 |
| T-02-06 | Tampering | src/esg_lens/collectors/newsapi.py enabled flag | mitigate | Collector checks settings.NEWSAPI_ENABLED default False and config/sources.yaml newsapi.enabled false before any HTTP; returns [] immediately; unit test asserts respx has zero calls when disabled |
| T-02-SC | Tampering | pip installs | mitigate | No new packages in this plan beyond those audited in RESEARCH.md; hishel/httpx/tenacity already audited as [OK]; no supply chain risk added |
