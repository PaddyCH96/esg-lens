## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| config file → HttpClient | sources.yaml provides rate limits and TTL; untrusted if file is user-editable |
| network → HttpClient (SEC/GDELT/Yahoo) | external HTTP responses cross trust boundary, no Cache-Control headers |
| ticker param → URL query | ticker is user-supplied but must never become URL host; only appears as query value or path segment after validation |
| collector → collection_runs table | collector writes observability rows with error text that must be truncated and parameterised |
